# Link values and services

`Domain\ValueObject\Link` is an extensible value object. It has no ID, owner or
repository. Its private fields have getters and constructor defaults; use a new
instance to replace a value. `equals()` compares values and concrete classes.
Subclasses may add behavior or typed constructor fields with matching getters.

```php
use Domain\ValueObject\{Link, LinkCollection, ShortText};

$link = new Link(url: new ShortText('example.org/path'), scheme: new ShortText('https'));
$links = (new LinkCollection())->addItem($link);
```

`LinkCollection` is generated by foreline/bundle's `value-object_collection`
generator. It preserves insertion order and duplicates. Reusing a PHP instance
does not imply a shared database row. Persistence is the consuming application's
responsibility: a single value may be embedded in the owner row, while a collection
may use owner-keyed value rows.

`ValueObjectData` encodes and decodes scalars, backed enums, constructor-based
mixed values and typed value collections at JSON/array boundaries. Unknown fields
and entity identifiers are rejected. Mixed values require named constructor types
and `get<Field>()` getters. Its flat-column codec supports scalar leaves and required
nested mixed values; it does not define an ORM or arbitrary object serialization.

`Link\Service\BuildLinkUri` and `ParseLinkUri` perform no I/O. HTML escaping belongs
to presentation. URI construction supports explicit ports, paths, IP addresses and
non-HTTP schemes, and suppresses executable browser schemes.

`Web\Service\ReadWebPageMetadata`, `FetchPublicWebResource` and `DecodeWebsiteIcon`
are framework-neutral and reusable outside Link (for example ContactData). Fetching
uses cURL with public-address validation, pinned DNS and redirect/size limits. Icons
are decoded to PNG; callers decide whether and where to store them. Metadata also
exposes the validated source icon URI. These operations require ext-curl, ext-dom
and ext-gd when used; constructing Link does not require them. No Bitrix types or
application protocol/file entities are imported by this package.

The shipped JSON config describes presentation only. Ownership and cardinality
come from PHP property types, not config flags.
